# Свадебный сайт Игоря и Марии

Сайт-приглашение на 20.02.2027. Состоит из одной страницы `index.html`, картинок в папке `assets` и генератора персональных ссылок `links.html`.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `wedding`, и загрузите в него содержимое этой папки.
2. Откройте Settings → Pages. В блоке Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)`, нажмите Save.
3. Через минуту-две сайт откроется по адресу `https://<логин>.github.io/wedding/`.

На бесплатном тарифе GitHub Pages работает только с публичным репозиторием, поэтому телефоны со страницы будут видны в коде. В поиск сайт не попадёт: на странице стоит запрет индексации.

## Анкета: Google Таблица и Telegram

Ответы гостей записываются в Google Таблицу и сразу приходят сообщением в Telegram.

### 1. Таблица и скрипт
1. Создайте новую Google Таблицу, например "Свадьба - ответы гостей".
2. В меню выберите Расширения → Apps Script.
3. Удалите всё в файле `Код.gs` и вставьте содержимое `apps-script/Code.gs`. Сохраните.

### 2. Telegram-бот
1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя и логин бота. BotFather пришлёт токен вида `123456:ABC...`.
2. Каждый, кто хочет получать уведомления, открывает бота и нажимает "Start".
3. В Apps Script откройте Настройки проекта (шестерёнка) → Свойства скрипта → Добавить свойство:
   - `TG_TOKEN` - токен от BotFather.
4. Вернитесь в редактор, выберите функцию `showChatIds` и нажмите "Выполнить". При первом запуске Google попросит разрешения, их нужно дать. В журнале появятся номера чатов.
5. Добавьте свойство `TG_CHAT_IDS` и впишите номера через запятую, например `123456789,987654321`.
6. Запустите `testRsvp`: в таблице появится лист "Ответы" с пробной строкой, а в Telegram придёт сообщение. Пробную строку потом можно удалить.

### 3. Подключение к сайту
1. В Apps Script нажмите Начать развертывание → Новое развертывание → тип "Веб-приложение".
2. Запуск от имени: от моего имени. У кого есть доступ: все. Нажмите "Развернуть" и скопируйте URL веб-приложения.
3. В `index.html` найдите строку `rsvpUrl: ''` и вставьте URL между кавычками.

Пока URL не вставлен, анкета работает в демо-режиме: гость видит "Спасибо", но ответ никуда не уходит.

Если позже поменяете код скрипта, разверните его заново через Управление развертываниями → Редактировать → Новая версия. URL при этом останется прежним.

## Персональные ссылки

Откройте `https://<логин>.github.io/wedding/links.html`, впишите обращения по одному в строке ("Дорогие Анна и Сергей!") и нажмите "Сделать ссылки". Гость по своей ссылке увидит своё обращение, а в таблице в колонке "Приглашение" будет видно, по какой ссылке пришёл ответ.

## Фото

Замените `assets/photo-1.jpg` и `assets/photo-2.jpg` своими фотографиями. Окошки в полароидах почти квадратные, поэтому лучше квадратные снимки; другие обрежутся по центру.
